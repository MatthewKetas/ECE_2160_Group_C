Source: http://www.bigrigg.com/ece1175/matrixmult.c

matrixmult.c was supplied by the user from the course example. Whitespace was
expanded from the pasted source; the logic, SIZE, random seed, and output remain
unchanged. The target is compiled with -O0 because its result is otherwise unused
and an optimizing compiler could remove the intended work. The collector archives
source/binary SHA-256 hashes. The loop supervisor repeats the executable to keep
competition present throughout collection; each invocation retains srand(time(NULL)).
